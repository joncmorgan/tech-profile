# CV Project Highlights

One curated blurb per project, keyed to the project id in vault/01-Projects/.
The active selection and display order for the CV is controlled by
cv/config.json, not by this file — this file just holds the wording for any
project that might be selected.

## richmond-window-film-retrofit
Richmond Window Film Retrofit — technical modelling demonstrated an external window film solution would resolve an overheating problem exposing the building owner to legal risk, securing planning approval and a multi-hundred-thousand-dollar retrofit contract.

## government-resilient-housing-prototype
Resilient Housing Prototype (State Government) — built a digital twin using spliced BOM heatwave data to stress-test a building envelope ahead of construction, informing a completed climate-adaptive housing prototype.

## future-climate-weather-file-application
Future Climate Weather File Application & Stress Testing — applied synthetic future-climate weather files to dynamic energy models, quantifying HVAC load and overheating risk in free-running buildings for adaptation planning and ESG reporting.

## city-of-melbourne-sustainable-building-standards
City of Melbourne Sustainable Building Standards & Resilient Refuges Strategy — technical sub-consultant helping identify a set of building specifications and an upgrade program to make existing council buildings more resilient to bushfire smoke and heatwaves.

## enterprise-data-driven-reporting-ecosystem
Enterprise Reporting & Documentation Engine — designed a data-to-deliverable pipeline (Knack database, PyLaTeX typesetting, containerised batch queuing) replacing manual assembly across ~10 technical reporting types.

## battery-energy-storage-systems-digital-twin
BESS Digital Twin for Local Government — wrapped NREL's SAM engine in a containerised Python application to right-size battery storage and test financial viability against tariff structures.

## low-income-public-housing-asset-energy-retrofit
Low-Income Public Housing Retrofit Platform — built a mobile-first Zoho data-collection framework combining building condition, occupant feedback and billing data to prioritise state-funded retrofits for vulnerable tenants.

## physics-informed-ml-surrogate-model
Physics-Informed ML Surrogate Model — trained regression models against multi-zone thermal simulations to cut dynamic building-performance prediction from minutes to milliseconds.

## bespoke-2.5d-to-3d-computational-geometry-engine
2.5D-to-3D Computational Geometry Engine — built a procedural pipeline turning 2.5D building plan definitions into watertight, simulation-ready 3D geometry near-instantaneously, without reliance on full 3D CAD workflows.

## victorian-local-government-technical-capacity-building
Victorian Local Government Technical Capacity Building (MAV/CASBE) — designed and delivered training for Victorian sustainability planners on auditing energy-modelling submissions, and contributed to refining the Built Environment Sustainability Scorecard (BESS) framework.
