# Gas Turbine Engine Digital Twin

## Context
Very first major job; acquiring and processing test bed performance data from Pratt & Whitney F404 aircraft engines run on a test bed at Fishermans Bend.

## Execution
- Simplex Algorithm Implementation: Programmed an iterative optimisation process in MATLAB using a downhill simplex algorithm.
- Parameter Degradation Modelling: Built simulation routines incorporating multiple thermodynamic parameter degradation vectors (such as turbine efficiency losses).
- Sensor Signal Matching: Systematically solved for the specific set of degradation parameters required to reconcile and match physical test bed sensor recordings of pressures, temperatures, fuel flows, and net thrust output.
